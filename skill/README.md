# Agensi skill package

The uploadable skill lives in `mj-prompt-factory/`. Zip that inner folder (so it contains `SKILL.md`, `README.md`, and `references/`) and upload the ZIP on Agensi. See `mj-prompt-factory/README.md` for install steps, the listing blurb, and official Midjourney sources.

Do not zip the whole git repository. Agensi looks for `SKILL.md` and ignores `.git` on upload.
